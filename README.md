# Mahdi Reverted — Personal Page

A responsive, animated personal biography landing page for GitHub Pages.

## Customize

Update the introduction in `index.html` with any biography details you want to share. The current page only uses the name and LinkedIn profile URL provided; it does not guess personal or professional details.

## Publish

This repository is named `mahdi-reverted.github.io`. In the repository settings, ensure GitHub Pages is enabled and set to deploy from the `main` branch (root). The site URL is https://mahdi-reverted.github.io/.
